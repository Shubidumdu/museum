# 🏛️ Shubidumdu Museum

Babylon.js를 기반으로 구축된 3D 인터랙티브 디지털 아트워크 전시 플랫폼입니다.  
Vite의 멀티페이지(MPA) 아키텍처 위에서 각 아트워크가 독립된 3D 씬과 셰이더 파이프라인으로 구동됩니다.
